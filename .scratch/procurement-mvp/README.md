# Procurement milestone backlog

Draft backlog derived from discovery. The first milestone is proposed: one durable procurement journey and one real, cited RAG answer using synthetic data. The architecture baseline is accepted with Foundry deferred; local identity and compatibility verification remain open. Definition of done and final UI layout still need confirmation. No implementation ticket is labelled ready-for-agent yet.

Markdown issue files in issues/ are authoritative. Status is triage readiness; Progress is execution progress. Blocked by refers to issue filename numbers. A dependency is satisfied only when its Progress is Done. Labels such as ready-for-agent do not mean completed.

The HTML register is generated from these files with `python3 tools/build-ticket-register.py`. It is a read-only snapshot, not a second editable tracker. Regenerate after editing issue files.
