# Start with one backend and an OpenRouter-backed agent

The first milestone uses React/TypeScript, Python/FastAPI, one in-process Microsoft Agent Framework agent, PostgreSQL for workflow records and full-text/vector retrieval, Floci Blob storage, and durable database jobs with one ingestion worker. This keeps the first real procurement/RAG journey inspectable while preserving module and provider boundaries for later scaling. The user accepted this baseline on 22 October 2026 and explicitly deferred Microsoft Foundry. Redis, external queue transport and distributed agents add dependencies without a measured first-milestone need, so they remain later options. Exact runtime versions, identity configuration and provider capabilities require validation before implementation readiness.
